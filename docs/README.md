# ParserKFile

ParserKFile — приложение для автоматизации подготовки расчетных моделей в программном комплексе «Логос Прочность».
Программа выполняет обработку K/CD-файлов конечно-элементных моделей, автоматически формирует наборы элементов (слои), рассчитывает начальное поле напряжений и генерирует корректный `.cd` файл для последующего численного моделирования.

## Функционал

- Парсинг K-файлов (`*NODE`, `*ELEMENT_SOLID`)

- Анализ конечно-элементной сетки

- Автоматическое формирование слоев

- Расчет начального поля напряжений

- Генерация `.cd` файлов для «Логос Прочность»

- Поддержка неоднородных расчетных сеток

- Асинхронная обработка больших моделей

- GUI-интерфейс на Tkinter

- CLI-режим для автоматизации и отладки

- Поддержка macOS (`.app`) и Windows (`.exe`)

## Область применения

Приложение предназначено для подготовки расчетных моделей в задачах:

- геомеханики;

- геофизики;

- моделирования грунтовых оснований;

- анализа напряженно-деформированного состояния;

- моделирования сейсмических воздействий.

Основная задача программы — автоматическое задание градиентно изменяющегося начального поля напряжений, возникающего под действием силы тяжести.

## Принцип работы

Алгоритм обработки состоит из следующих этапов:

1. Чтение входного `.k` файла

2. Извлечение узлов (`*NODE`) и конечных элементов (`*ELEMENT_SOLID`)

3. Фильтрация элементов по подобласти

4. Анализ геометрии расчетной модели

5. Формирование горизонтальных слоев

6. Расчет напряжений для каждого слоя

7. Генерация промежуточных данных

8. Автоматическая вставка данных в `.cd` файл

9. Формирование итогового `_output.cd`

#### Результаты тестирования

После автоматического задания начального поля напряжений:

- амплитуда остаточных колебаний уменьшается в 8–10 раз;

- ускоряется выход системы в стационарное состояние;

- уменьшается влияние переходных процессов;

- повышается устойчивость расчета;

- улучшается качество подготовки исходных данных.

Для крупных моделей уменьшение амплитуды колебаний достигало более чем 2000 раз.

## Запуск проекта

### Готовое приложение

Скачайте актуальную версию из раздела Releases:

- macOS (`.app`)

- Windows (`.exe`)

### Запуск из исходного кода

#### Клонирование репозитория

```bash
git clone https://github.com/Kurillccc/ParserKFile
cd ParserKFile
```

#### Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate

# Windows
.venv\Scripts\activate

```

#### Установка зависимостей

```bash
pip install -r requirements.txt

```

#### Запуск GUI

```bash
python run.py

```

#### Запуск CLI

```bash
python app/cli.py --input path/to/file.k
```
